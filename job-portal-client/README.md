# CareerConnect - MERN Job Portal

CareerConnect is a full-stack MERN Job Portal that connects job seekers with recruiters. Users can search jobs, apply for positions, manage applications, and recruiters can post and manage job listings.

## Features

* User Authentication (Login & Signup)
* Recruiter and Candidate Roles
* Job Search and Filtering
* Job Posting and Management
* Salary Estimation
* Responsive Design
* Modern React UI
* MongoDB Database Integration

## Tech Stack

### Frontend

* React.js
* React Router
* Tailwind CSS
* Vite

### Backend

* Node.js
* Express.js
* MongoDB
* JWT Authentication

## Installation

### Clone Repository

```bash
git clone https://github.com/Aamir2004/mern-job-portel.git
```

### Install Dependencies

Frontend:

```bash
cd job-portal-client
npm install
npm run dev
```

Backend:

```bash
cd job-portal-server
npm install
npm start
```
